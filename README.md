# C++ Code Similarity Detection System

## Introduction
A research project for detecting source code similarity
and potential plagiarism in C/C++ programming assignments.

## Objectives
- Implement traditional code similarity algorithms.
- Analyze code structure using AST.
- Explore CodeBERT embeddings.
- Combine multiple similarity methods.
- Evaluate performance using experimental datasets.

## Technologies
- Python
- Tree-sitter
- PyTorch
- CodeBERT
- FastAPI
- React

## Project Structure
- src/: Core research modules
- data/: Datasets and processed data
- backend/: API server
- frontend/: User interface
- experiments/: Experimental configurations and results
- tests/: Unit tests
